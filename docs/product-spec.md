# 羽毛球双打战术实验室：产品规格

## 目标

帮助普通羽毛球爱好者理解双打的击球选择、搭档覆盖与下一拍准备。产品提供教学建议，不承诺比赛结果，也不把内部推荐评分解释为概率。

## 预设教学与连续自由推演

1. 创建或编辑四张独立球员名片，选择正式男双、女双、混双或自定义训练组合。
2. 五个基础入口进入 2–4 拍引导教学。自由推演允许拖动四人和羽毛球、选击球者、画线并连续推演五拍以上。两种流程共用逐拍核心引擎。
3. 画线只推测球种，用户确认之后才计算。分别显示规则／物理成立性、五档执行难度和战术质量，并解释四人跑位、搭档补位与证据。非法或信息不足时允许零条建议。
4. 引擎列出可达接球人；两人可达时由用户选择。无人可达时默认结束，可显式采用训练假设。逐人“保持原位”真实改变下一拍位置。本版不开放手动拖动跑位。
5. 自由回合支持播放、暂停、三档速度、逐阶段讲解、撤销、重做、历史分支与跑位对比；旧节点重播只读快照。
6. 在本设备浏览器保存球员名片、旧教学局面与自由回合。IndexedDB v2 保留旧数据。清除浏览器数据可能导致数据丢失。

## 内容与界面

- 全部可见界面和默认解释采用简体中文；高级解释显示覆盖、回球角度、重心与主动权等条件。
- 首次访问提供进攻前后站、防守左右站、后场进攻搭档封网、接发后跑位、打中路五个入口。
- 桌面展示预设列表、球场和分析面板；手机优先展示球场，设置和分析采用可收起面板。
- 球场使用米制世界坐标，屏幕采用斜视投影；运动与羽毛球轨迹是教学启发式估算，不精确预测真实到位时间。
- 证据页显示当前依据的竞赛规则版本，并提供资料来源链接。第三方资料仅保存来源索引与原创中文归纳。

## 边界

- 不设账户、云同步、社区或运行时 AI API。
- 非正式的双方组合统一标记“自定义训练组合”。
- 性别不自动改变能力值；混双传统站位是教材中的情境，不是必须遵守的能力判断。
- 不为凑足推荐数量或预设数量制造未经核验的内容。
- 每次击球的 T2 实际位置是下一拍真实起点；用户选择“保持原位”后，引擎不得暗中修正站位。
